# 프로젝트: 조건 기반 자리 배정

교실 좌석 격자(가로 × 세로)와 사용자가 입력한 배치 조건을 받아, 조건을 모두 만족하는
자리 배치를 만들고 **그림 배치표**로 보여 주는 프로젝트입니다.
이 폴더에서 작업할 때만 이 지침을 적용합니다. (저장소의 다른 두 프로젝트와 무관합니다.)

---

## 1. 세션 진행 순서 — 반드시 이대로

1. **격자 크기 확인**
   - 저장된 격자가 없거나 설정 후 **1년이 지난 경우에만** "가로 몇 칸 × 세로 몇 칸인가요?"를 묻는다.
   - 저장값이 1년 이내면 **다시 묻지 않고** 현재 값을 한 줄로 알려 주기만 한다.
2. **학생 명단 확인** — 저장된 명단이 있으면 인원수만 알려 주고 넘어간다. 없으면 한 번 받는다.
3. **조건 확인** — 저장된 조건 목록을 모두 보여 준 뒤 **"조건을 수정할까요?"는 매 세션 반드시 묻는다.**
   - 수정하지 않는다고 하면 저장된 조건을 그대로 적용한다. 조건은 세션이 바뀌어도 그대로 유지된다.
   - 사용자가 자연어로 새 조건을 말하면 아래 §4 조건 스키마로 옮겨 `--조건추가` 로 저장한다.
4. **배치 생성 → 그림 제시** — 완성된 배치표를 보여 주고 **"배치를 수정할까요?"를 묻는다.**
   - 채팅에는 텍스트 배치표를 그대로 붙여 주고, `출력/배치표_*.html`(조건 목록 포함)·`.svg`,
     `출력/배치표_*_A4.html`·`_A4.svg`(조건 목록 없이 배치표만, A4 가로 1장) 경로를 함께 알린다.
   - 수정 요청이 오면 ①다시 섞기 ②조건 수정 후 재배치 ③두 학생 자리 맞바꾸기 중에서 처리하고
     다시 그림을 보여 준 뒤 같은 질문을 반복한다.
5. **확정** — 배치를 저장하고 마지막 줄에 **`완료.`** 만 출력한 뒤 세션을 끝낸다.
   - `완료.` 이후에는 추가 작업·추가 질문을 하지 않는다.

배치가 불가능하면 임의로 조건을 무시하지 말고, 충돌이 의심되는 조건을 짚어 사용자에게 알린다.

## 2. 저장 위치

| 경로 | 내용 | 커밋 여부 |
|---|---|---|
| `데이터/settings.json` | 격자 크기·설정일, 학생 명단, 조건 목록, 최근 배치 | **커밋 금지**(개인정보) |
| `출력/배치표_*.html`, `*.svg` | 생성된 배치표 그림 | **커밋 금지**(개인정보) |
| `예시/` | 형식 설명용 가짜 데이터 | 커밋함 |
| `scripts/` | 실행 코드 | 커밋함 |

학생 이름·명단은 이 폴더의 `데이터/`·`출력/` 밖으로 내보내지 않는다. 저장소 루트 `.gitignore`가
두 폴더를 제외하고 있으므로 `git add -f` 로 강제 추가하지 않는다.

## 3. 실행 방법

```bash
cd 자리배정

# 대화형 전체 흐름(위 1~5단계를 순서대로 진행)
python3 scripts/seat_assign.py

# 사용자가 채팅으로 값을 주는 경우 — 필요한 것만 옵션으로 반영
python3 scripts/seat_assign.py --격자 6x5            # 가로 6칸 × 세로 5칸
python3 scripts/seat_assign.py --학생 명단.txt       # 또는 --학생수 28
python3 scripts/seat_assign.py --조건추가 "홍길동 앞자리" --조건추가 "홍길동 김철수 분리"
python3 scripts/seat_assign.py --조건삭제 2
python3 scripts/seat_assign.py --배치 --씨드 7 --제목 "3학년 7반 2학기"   # 질문 없이 배치
python3 scripts/seat_assign.py --상태                # 저장된 격자·명단·조건 확인
python3 scripts/seat_assign.py --조건도움말          # 조건 문장 문법

python3 scripts/test_seat_engine.py                  # 자체 점검(코드 수정 후 반드시 실행)
```

`--씨드` 값이 같으면 같은 배치가 나온다. 값을 바꾸면 조건은 지킨 채 다른 배치가 나온다.

## 4. 조건 표현

좌표 약속: **1행 = 교탁과 가장 가까운 맨 앞줄**, **1열 = 칠판을 볼 때 가장 왼쪽**,
분단 = 좌우로 붙은 2열 묶음. 조건과 저장 데이터는 **항상 이 학생 기준 좌표**로 적는다.

그리는 방향(`교실.보기`)은 이와 별개다. 기본값 **`교사시점`** — 교사가 교탁에서 학생을 바라본
그대로, 위에서 아래로 뒷줄→앞줄(4행…1행), 왼쪽에서 오른쪽으로 마지막 열→1열, 교탁은 그림 아래.
`학생시점`으로 바꾸면 1행이 맨 위·1열이 맨 왼쪽·교탁이 위로 간다 (`--보기 학생시점`).

사용자 문장 → 저장되는 조건(JSON):

| 사용자가 말하는 방식 | 저장되는 조건 |
|---|---|
| 홍길동은 3행 2열 고정 | `{"종류":"고정","대상":"홍길동","행":3,"열":2}` |
| 홍길동 앞자리 / 앞에서 2줄 이내 | `{"종류":"영역","대상":"홍길동","행범위":[1,2]}` |
| 홍길동 맨뒤 | `{"종류":"영역","대상":"홍길동","행범위":[-1,-1]}` (음수 = 뒤에서부터) |
| 홍길동 맨뒤 금지 | `{"종류":"금지","대상":"홍길동","행범위":[-1,-1]}` |
| 홍길동 창가 / 복도 / 왼쪽 / 가운데 | `{"종류":"영역","대상":"홍길동","열범위":"창가"}` 등 |
| 홍길동·김철수 짝꿍 | `{"종류":"짝꿍","대상들":["홍길동","김철수"]}` |
| 홍길동·김철수 가까이 | `{"종류":"근처","대상들":[...],"최대거리":2}` |
| 홍길동·김철수 떼어놓기 | `{"종류":"분리","대상들":[...],"최소거리":2}` |
| 셋 이상 서로 다른 분단 | `{"종류":"분단분리","대상들":[...]}` |
| 짝은 남녀로 | `{"종류":"남녀짝"}` |
| 1행 1열은 비움 | `{"종류":"빈자리","자리들":[[1,1]]}` |

- 거리는 칸 단위(가로·세로·대각선 중 큰 값). `분리`의 기본값은 2칸이다.
- `창가`가 어느 쪽인지는 `데이터/settings.json` 의 `교실.창가`(`왼쪽`/`오른쪽`)로 정한다.
- 학생 수가 자리보다 적으면 **앞줄부터 채우고 남는 자리는 뒤쪽에 모은다**
  (`교실.빈자리`를 `"자유"`로 바꾸면 전체에 흩어 놓는다).
- 위 표에 없는 새 조건 종류를 임의로 만들지 않는다. 표현이 안 되면 사용자에게 다시 묻는다.

## 5. 코드 구조

- `scripts/seat_engine.py` — 설정 저장/불러오기, 명단·조건 파싱, 배치 탐색(백트래킹),
  텍스트·SVG·HTML 그리기, 충돌 조건 진단.
- `scripts/seat_assign.py` — 위 1~5단계 세션 흐름을 담당하는 실행 스크립트(대화형 + 옵션).
- `scripts/test_seat_engine.py` — 자체 점검. 코드를 고쳤으면 반드시 통과시킨 뒤 커밋한다.
